# 校园互助平台 (PE-Student)

一个面向高校学生的移动端互助平台，旨在促进校园内的信息共享、资源互助与社交互动。平台以"互助、共享、连接"为核心理念，打造温暖、年轻、有活力的校园社区。

## 项目简介

校园互助平台提供以下核心功能：

- **帖子发布**：文字/图片发帖、话题标签、分类选择
- **二手交易**：商品发布、价格展示、交易状态、分类筛选
- **互动系统**：点赞、评论、收藏
- **私信系统**：一对一聊天、消息列表
- **用户中心**：个人资料、我的帖子、我的交易、收藏管理

| 技术 | 版本 | 用途 |
|------|------|------|

## 快速开始

### 环境要求

- Node.js 18+
- npm 9+ 或 pnpm 8+

### 安装依赖

```bash
cd student-app
npm install
```

### 开发模式

```bash
npm run dev
```

### 生产构建

```bash
npm run build
```

### 预览生产构建

```bash
npm run preview
```

### 页面列表

| 页面 | 路径 | 描述 |
|------|------|------|
| 首页 | `/` | 信息流、推荐内容 |
| 搜索 | `/search` | 关键词搜索 |
| 帖子详情 | `/post/:id` | 帖子内容、评论列表 |
| 发布帖子 | `/post/create` | 创建新帖子 |
| 二手市场 | `/trade` | 商品列表 |
| 商品详情 | `/trade/:id` | 商品信息 |
| 发布商品 | `/trade/create` | 发布二手商品 |
| 消息列表 | `/message` | 会话列表 |
| 聊天页面 | `/message/:userId` | 私信聊天 |
| 个人中心 | `/user` | 用户信息 |
